# 圖片資源目錄 (`public/images/`)

將你的兩張珠海大劇院（日月貝）圖片放入此目錄並命名為：

1. **白天版**：`zhuhai-opera-day.jpeg`（對應你上傳的 `Gemini_Generated_Image_ylhbmaylhbmaylhb.jpeg`）
2. **黑夜亮燈版**：`zhuhai-opera-night.jpeg`（對應你上傳的 `Gemini_Generated_Image_tr1228tr1228tr12.jpeg`）

> **提示**：你也可以直接把原文件名的兩張圖片放到本目錄下，然後在項目根目錄運行 `python3 scripts/prepare-images.py`，腳本會自動識別哪張是白天、哪張是黑夜，並自動完成重命名與背景融合優化。
